## Project Overview

This project is a voice-interactive AI chatbot that communicates with a remotely hosted AI model through a network.
The system will take voice input from the user, send the query to the AI service, receive the AI-generated response, and provide the response through audio output.

## Project Features
- Voice input from the user
- Network communication with the AI service
- AI-generated responses
- Voice output
- Short back-and-forth conversation
- Network failure handling
- Latency measurement
- Error handling
